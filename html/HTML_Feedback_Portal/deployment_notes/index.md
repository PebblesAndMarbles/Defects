# Deployment Notes Index

Log of every workspace deployment/customization of the HTML Feedback Portal
template, written back here so learnings and edge cases accumulate centrally
instead of being lost in individual workspaces.

Notes are written **only when the user explicitly asks** (e.g. "log this
deployment", "write a deployment note") — not automatically after every
scaffold. See `Agent_Templates\.github\agents\html_feedback_portal.agent.md`
for the agent instructions that produce these notes.

## How to add a row

After saving a new note file as `YYYY-MM-DD_<workspace>_<short-title>.md`,
append a row above with: date, workspace name, short title, whether the note
suggests a change to the canonical template (Y/N), and a relative link to the
file.
