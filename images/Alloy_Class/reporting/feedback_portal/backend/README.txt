Feedback Portal — probe_review.html

What this is
-------------
Local Flask server providing /submit_feedback and /feedback for the
probe_review.html report generated by
reporting/build_probe_html_report.py --with-feedback-portal.

Unlike the generic html/HTML_Feedback_Portal template, this server does NOT
serve the report page itself -- probe_review.html is a static file that
lives next to its own images in an outputs/probes/scored/<run_id>/ folder
and is opened directly (file://). This server only needs to be running in
the background so the page's feedback-submit fetch() calls succeed.

Run instructions
-----------------
1. Ensure Flask is installed in your Python environment:
     pip install -r requirements.txt
   (If pypi.org is blocked, confirm Flask is already present in your
   managed Python install first.)

2. Start the server (defaults to the run baked into main.py's DATA_FILE):
     python backend/main.py
   or, to point at a different run's output folder without editing
   main.py, use the launcher one directory up:
     run_portal.cmd                                  (double-click, default run)
     run_portal.ps1 -DataFile <path\to\probe_review_feedback.csv>

3. Open the report directly in a browser (double-click the .html file, or
   File > Open):
     outputs/probes/scored/<run_id>/probe_review.html
   Leave the server running in the background for feedback submission to
   work -- the page's fetch() calls target http://127.0.0.1:8000 directly
   since the report is opened via file://.

Where feedback goes
---------------------
DATA_FILE in main.py (or -DataFile on the launcher / FEEDBACK_DATA_FILE
env var) -- a CSV of case_id/reviewer/submitted_at_utc/agrees_with_vlm/
corrected_class/comment/run_id rows, one appended per submission (not
overwritten), living next to the run's probe_scored_cases.jsonl so it can
be joined back by case_id.

When a new report run needs review
------------------------------------
Point -DataFile at the new run's output folder -- do not edit main.py's
DATA_FILE constant per run. Old runs' feedback CSVs are left untouched.
