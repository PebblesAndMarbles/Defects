1a. Coarse Shape -- SINGLE-select
Circle
Round
Angular
Clumped

[CHANGE] add an explicit instruction that the answer must be exactly one of these
four words: circle, round, angular, clumped. Removing Shard (see 1b) fixes that
specific v6 collision (model output coarse_shape="shard", echoing the fine-flag
name instead of a valid coarse value), but Elongated/Jagged/Concave remain as
fine-shape terms the model could still reach for under the same failure pattern --
this explicit constraint is defense in depth, the same fix already applied to
location_relative below.

Calibration guidance:
  - Circle: reserve for a close-to-true circular/disc outline only -- smooth and symmetric all the way around, with no facet or notch anywhere on the boundary. Prefer Round or Angular when not clearly circular rather than defaulting to Circle under uncertainty.
  - Round: soft/blobby outline, no circle-level regularity and no straight/angular edges.
  - Angular: at least one relatively straight edge or corner-like feature is visible.
  - Clumped: reserve for ONE outline that itself looks fused/multi-lobed (multiple bumps/lobes on a single connected silhouette, ambiguous whether it's one particle or several merged). Do not use Clumped just because defect_count > 1 with clearly separate, individually-outlined particles -- describe each particle's own shape instead.

1b. Fine Shape -- independent True/False
Elongated - True if defect outline aspect ratio is high, at least 2x approximate length:width
Rounded_Corners - True if defect outline has corners that are round, instead of mostly sharp angles
Jagged - True if defect outline contains sharp angled vertices
Concave - True if noticeable portion of defect outline has inward curve departing meaningfully from convex shape--ignoring surface irregularities
Flake — True if defect appears to be a flat, thin fragment with an irregular but relatively planar outline, like a broken chip or flake of material. False otherwise

2a. Coarse Texture (implied height/relief) -- SINGLE-select, ordinal low-to-high relief
Smooth
Textured
Rough

[CHANGE] Calibration anchor added: assess relative to the SiO substrate's own
visible texture wavelength (the substrate is not perfectly flat -- it has its
own relatively uniform, bumpy grain), rather than as an absolute judgment call.
  - Textured: defect surface relief is comparable in scale/wavelength to the
    substrate's own texture.
  - Rough: defect surface relief is visibly coarser (larger-scale
    bumps/features) than the substrate's texture.
  - Smooth: defect surface relief is finer than the substrate's texture, or
    not visibly present at that scale.

2b. Fine Texture -- independent True/False, three binary triggers now clearly
distinguished from each other:
Interior_Layer - True if line(s) or a contrast boundary within defect follows outer boundary (the defect's own outline -- not a comparator edge; the comparator-edge-following trigger from v6 is intentionally dropped here)
Interior_Line - True if there is a straight line within defect boundary
Interior_Fracture - True if a visible, irregular gap/break separating or nearly separating primary defect into multiple pieces
Scraggly - True if defect shows craggy or nodular surface with numerous small knobs/lobes giving cauliflower impression


3. Aggregation/Count
defect_count -- quantitative int. Known to sometimes undercount fused/clumped
particles as a single defect; coarse_shape=Clumped is the intended hedge for that
case (see 1a).

4. Size
size_percent_of_image -- quantitative float, model's visual estimate of defect area
as a percent of total image area. Binning into categorical size labels is deferred
until the distribution across a larger sample is known.

5. Position
location_relative -- single-select: on_sio / in_comparator / spanning_both / unclear.
[CHANGE] wording restructured to separate the enum list from its explanation, after
a v5 case (SMP_PILOT_013) returned the literal phrase "touches without crossing"
instead of a valid enum value -- the model had echoed a phrase from the definition
text itself. Definitions unchanged in meaning:
  - on_sio: defect either (1) does not touch a comparator's real or inferred boundary
    at all, or (2) touches that boundary but does not cross over/into it (stays fully
    on the SiO side).
  - in_comparator: defect is fully within a comparator's real or inferred boundary.
  - spanning_both: defect's own edge crosses at least one comparator's real or
    inferred boundary line (part of the defect on the SiO side, part on the
    comparator side).

6. Image Quality
focus_quality -- single-select: in_focus / out_of_focus / mixed.
